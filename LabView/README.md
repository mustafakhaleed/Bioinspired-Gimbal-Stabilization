# LabVIEW Simulations & GUI
This folder contains the Virtual Instruments (VIs) used for system validation.

### Included Files:
* `Bioinspired Stabilizing System Dynamic Modeling and Control... .vi`: The main interface for real-time monitoring of gimbal angles.
* `Calibration uncontrolled .vi`: A utility for calibrating the IMU to eliminate gyroscopic drift and sensor offsets.
